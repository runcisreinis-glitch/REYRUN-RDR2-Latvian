# Как перевести игру на латышский с помощью REYRUN

<img src="https://reyrun-rdr2-latviski.runcisreinis.chatgpt.site/assets/reyrun.png" width="56" alt="REYRUN" />

Если вы хотите пройти Red Dead Redemption 2 на латышском, скачайте готовый перевод и инструкцию по установке с [сайта проекта](https://reyrun-rdr2-latviski.runcisreinis.chatgpt.site/ru/). Чтобы перевести другую игру или отредактировать её текст, скопируйте папку `reyrun-game-translation-lv`. В ней находятся порядок работы, пять учебных примеров и локальные тесты.

После первого упражнения переходите к [проверке текста в игре](https://reyrun-rdr2-latviski.runcisreinis.chatgpt.site/ru/method/techniques/). Как мы восстанавливали черновики и находили очереди уже вычитанных строк, с конкретными числами разбираем в [истории перевода RDR2](https://reyrun-rdr2-latviski.runcisreinis.chatgpt.site/ru/method/retrospective/).

## Как работать самостоятельно или с ИИ-помощником

В обычном чате прикрепите `SKILL.md`, эту инструкцию и несколько исходных строк. В системе, которая читает Agent Skills из каталога, скопируйте **всю папку** в каталог навыков, обновите список и выберите `reyrun-game-translation-lv`. Ссылки на инструкции и скрипты внутри навыка относительные. Переводчик может редактировать и сами файлы JSONL вручную. Проверки запускаются в Python. Платный аккаунт или конкретный ИИ-сервис для этого не требуются.

Для первого упражнения прикрепите `examples/source.jsonl` и отправьте помощнику просьбу:

> Прочитай SKILL.md. Переведи пять исходных строк целиком на латышский. Сохрани все поля входных данных без изменений. Добавь target, decision и reason. Если строка неоднозначна, отложи её и напиши, что нужно узнать для точного перевода. Верни по одному объекту JSON на строку, без пояснений вокруг. Я проверю результат перед добавлением в игру.

Сохраните ответ в файле `my-edits.jsonl` с кодировкой UTF-8. Сравните решения с `examples/edited.jsonl`. Правильных формулировок может быть несколько. Уточните, что именно предлагается сделать игроку. Прочтите реплику свидетеля вслух, проверьте подсказку управления и посмотрите, какая строка осталась до выяснения контекста.

## Пройдите один цикл на примере

Откройте терминал в папке навыка. Нужен Python 3.8 или новее. В Windows может потребоваться команда `py -3` вместо `python`.

``` sh
python scripts/localization_tools.py prepare examples/source.jsonl --output demo-packets --max-rows 2
python scripts/localization_tools.py validate --inputs examples/source.jsonl --edited examples/edited.jsonl --report demo-qa.json
python -B -m unittest discover -s scripts -p "test_*.py"
```

Первая команда создаёт три файла с двумя, двумя и одной строкой. Вторая находит пять исходных ID: четыре строки помечены готовыми, одна отложена. Строка со счётом состоит из аргументов и разделителей. Её оставили без изменений, поэтому предупреждение ожидаемо. Повторите вторую команду с `my-edits.jsonl` и новым именем отчёта. Чтобы увидеть ошибку в тестовой копии, удалите `~INPUT_INTERACT~` **только из перевода**. Проверка укажет строку и завершится с кодом 2. Существующие результаты защищены от перезаписи, поэтому выбирайте новую папку или новое имя отчёта для каждого запуска.

## Подготовьте исходные строки своей игры

Выгрузите текст инструментом самой игры. Сохраните исходный файл, номер сборки, имя ресурса и его внутренний ключ. За один проход работайте с одним пространством имён и одной сборкой. Входные данные могут быть массивом JSON в UTF-8 или файлом JSONL с одним объектом на строку. Если ресурсы повторно используют одни и те же ID, проверяйте их по отдельности. Контрольная сумма исходника в этом формате вычисляется как SHA-256 декодированной строки в UTF-8 без добавочного перевода строки. Например, `hashlib.sha256(source.encode("utf-8")).hexdigest()`.


| Поле                                                        | Что указать                                                                                                                                                                 |
|-------------------------------------------------------------|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `id`, `native_id`                                           | Уникальный постоянный рабочий ID и, если он известен, точный ключ в игре. После обновления языкового пакета номера строк могут измениться. Сохраните настоящий ключ.        |
| `source`, `source_sha`                                      | Полный исходный текст со служебными кодами и пробелами и его контрольная сумма.                                                                                             |
| `candidate`                                                 | Предыдущий черновик или пустая строка, если перевод новый.                                                                                                                  |
| `context`, `context_id`, `speaker`, `scene_id`, `branch_id` | Проверенные сведения о говорящем и о том, что видит игрок. Не добавляйте в запись поля, значения которых неизвестны. Соседние ID сами по себе не определяют порядок реплик. |
| `target`, `decision`, `reason`                              | Предлагаемый текст на латышском, принятое решение и вопрос или исключение, если они есть. Эти поля добавляют только в отредактированные строки.                             |


Раздавайте исполнителям разные ID. Передайте им утверждённые написания имён, названий мест и повторяющихся терминов с примерами употребления, в том числе в косвенных падежах. Для всей партии берите одну версию этих материалов. Если в сцене персонажи переходят с «вы» на «ты», отметьте место перехода.

## Отредактируйте смысл и речь персонажей

Это учебные примеры, написанные специально для руководства. Цитаты из RDR2 приведены отдельно.


| Исходный текст и ситуация                                                                         | Вариант на латышском                                       | На что обращает внимание редактор                                                                                                                                                            |
|---------------------------------------------------------------------------------------------------|------------------------------------------------------------|----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| «Resume» в меню паузы                                                                             | **Turpināt**                                               | Короткая подпись действия помещается на кнопке.                                                                                                                                              |
| “Hold `~INPUT_INTERACT~` to open the gate.”                                                       | **Turi nospiestu `~INPUT_INTERACT~`, lai atvērtu vārtus.** | Клавишу нужно удерживать. Короткое нажатие означало бы другое действие.                                                                                                                      |
| «I... I didn't take it.» Взволнованный свидетель                                                  | **Es… Es to nepaņēmu.**                                    | Сохраните заминку и отрицание. Прочитайте реплику вслух.                                                                                                                                     |
| «Can you wait here?» Ребёнок обращается к другу; служащий вежливо спрашивает незнакомого человека | **Vari te pagaidīt?** / **Vai jūs varētu te pagaidīt?**    | Обращение зависит от отношений и принятого между собеседниками тона.                                                                                                                         |
| «Charges: {count}». Счётчик зарядов меняется                                                      | **Lādiņu skaits: {count}**                                 | Если движок выводит одну строку, подберите подпись, которая сочетается с любым числом. Если у движка отдельные формы множественного числа, переведите и проверьте каждую используемую форму. |
| «Seal» без сцены или типа предмета                                                                | **hold**                                                   | Уточните, означает ли слово тюленя, печать или действие. Затем подберите слово на латышском.                                                                                                 |


До утверждения дважды прочитайте исходную строку и перевод целиком. Сначала проверьте смысл, отрицания, действующее лицо и адресата, условия и последствия действия. При втором чтении проверьте речь персонажа, латышские окончания, длину субтитра и ограничения интерфейса. Словарь поможет с написанием, а для выбора между разными значениями нужен контекст. Храните утверждённый перевод вместе с записью о проверке. После правки прочитайте новую версию ещё раз.

## Проверьте перевод, соберите выпуск и запишите, где остановились

Валидатор проверяет хеши исходников, уникальность ID, полноту набора, известные поля контекста и наличие пустых переводов среди готовых. Он сверяет порядок маркеров с тильдами, как в RDR, простые аргументы в фигурных скобках и распространённые форматы printf. Полностью пронумерованные аргументы printf можно переставлять по смыслу. Типы неявных аргументов должны идти в прежней последовательности. Два одинаковых ненумерованных `%s` могут поменяться значениями, поэтому редактор проверяет, что появится в каждом месте. При изменении переносов строк валидатор выдаст предупреждение. Если игра использует вложенные выражения ICU, HTML, команды шрифтов или собственные коды управления, добавьте разбор или тест именно для её формата.

Дополнительные команды `tm-index` и `tm-suggest` предлагают уже проверенные переводы. В ключ входят игра, язык, контрольная сумма исходника, ID контекста и версии контекста, правил и терминологии. Укажите ссылку на проверку и контрольные суммы одобренного перевода и файла проверки. При относительных путях сохраняйте тот же рабочий каталог. Два разных одобренных варианта для одного ключа попадут в список конфликтов. Команда `python scripts/localization_tools.py --help` выводит справку.

Запустите пример из папки навыка. Запись о проверке относится к глаголу «Turpināt» в меню паузы. Обе команды используют одну версию контекста; результатом будет одна подсказка.

``` sh
python scripts/localization_tools.py tm-index examples/tm-approved.jsonl --output demo-tm.json
python scripts/localization_tools.py tm-suggest examples/tm-query.jsonl --index demo-tm.json --output demo-suggestions.json
```

Соберите выпуск адаптером конкретной игры. Храните технические исключения и нерешённые строки в отдельных списках. Скопируйте старый игровой файл за пределы папки игры. Заменять его должен один процесс после проверки, что вычитанный снимок соответствует нужной сборке. Для экспорта RDR2 StringTable выполните следующую команду с реальными путями. Она сравнит *всю* таблицу по числовым ID игры и точному декодированному тексту и покажет хеши обоих файлов. Порядок строк или способ записи XML могут изменить байтовый хеш, даже когда все пары ID и текста совпадают.

``` sh
python scripts/compare_xml.py "reviewed/Latvian Translation.xml" "installed/Latvian Translation.xml"
```

Откройте нужный режим игры. Проверьте меню, реплику с ограниченным временем показа, длинное название предмета и переменную с несколькими значениями. Обратите внимание на буквы **ā, č, ē, ģ, ī, ķ, ļ, ņ, š, ū, ž**. Сообщая об ошибке, сохраните номер сборки, ID, если он известен, исходную строку, текущий перевод, сцену и скриншот. Оставьте под рукой последний принятый выпуск для восстановления.

После каждой партии запишите хеш последнего установленного выпуска, утверждённый снимок и ещё отложенные ID. Подсчитывайте новые установленные ID и исходные символы за прошедший час. Отдельно учитывайте время перевода, вычитки, экспорта и ожидания. После перерыва сначала сравните реальный игровой файл с сохранённой записью и только потом раздавайте работу.
