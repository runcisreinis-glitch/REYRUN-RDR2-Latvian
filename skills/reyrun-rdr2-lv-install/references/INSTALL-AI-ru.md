## Как помощнику работать с файлами на компьютере

В обычном чате достаточно отправить просьбу и ссылку на эту инструкцию. Папки открывает сам игрок. При необходимости он может передать список имён файлов. Чтобы помощник сам копировал файлы, используйте уже установленного локального помощника или одобренное игроком подключение к файлам. Для работы хватит трёх папок: выбранной папки RDR2, папки загрузки или подготовки и папки резервных копий.

Разрешённые папки выбирает игрок в настройках подключения. Сначала попросите помощника найти файл `RDR2.exe` в выбранной папке игры. При установке разрешите записывать и копировать только указанные ниже файлы. Пароли и ключи доступа в чат не отправляйте. Если помощник видит только вложения, он может объяснить игроку, как скопировать файлы вручную. Если Windows защищает папку от записи, покажите точные пути источника и назначения. Игрок сможет подтвердить копирование в Windows. Если доступ получить не удалось, остановитесь на этом шаге. Менять настройки сетевого доступа, брандмауэра или защиты папок для установки не требуется.

[Скачать программу для Windows](https://reyrun-chatbot-bridge.runcisreinis.chatgpt.site/launchers/REYRUN-rdr2-Windows.cmd) Откройте скачанный файл .cmd. Он найдёт игру, установленную через Steam, Rockstar или Epic, проверит контрольную сумму SHA-256 и подготовит копию XML с переводом в рабочей папке REYRUN. Если появится запрос, укажите папку с RDR2.exe. Дальше по инструкции установите плагин перевода и загрузчик ASI, затем скопируйте XML в папку игры. ### Локальное подключение к трём папкам

Этот вариант подходит для настольного ИИ-клиента, который умеет запускать локальный сервер MCP через `stdio`. Подключение работает между двумя программами на компьютере игрока. Публичный адрес, туннель и ключ API не нужны. В браузерном чате без такой функции помощник может объяснять шаги для ручной установки. Достаточно одного локального подключения к файлам.

1.  Найдите папку игры по разделу 1. Создайте за её пределами две другие папки: для распакованных загрузок и резервных копий. Запишите все три пути.
2.  Для этого примера нужны Node.js 24 или новее и npm. Выполните `node --version` и `npm.cmd --version`. Если Node.js отсутствует, скачайте официальный установщик LTS для Windows или продолжите вручную. Убедитесь, что команда `npm.cmd view @modelcontextprotocol/server-filesystem@2.3.0 version` находит указанную версию пакета. [Скачать Node.js](https://nodejs.org/en/download) · [Требования пакета для работы с файлами](https://github.com/modelcontextprotocol/servers/blob/main/src/filesystem/package.json)
3.  Например, в Claude Desktop откройте **Settings → Developer → Edit Config**. В Windows файл находится по адресу `%APPDATA%\Claude\claude_desktop_config.json`. Сохраните его копию. Если в нём уже есть объект `mcpServers`, добавьте в него только запись `rdr2-files`. Замените три примера путей настоящими, по одной строке JSON на папку. В JSON обратную косую черту пишут дважды. Проверьте, что Node.js и `npx-cli.js` лежат по указанным адресам. Если Node.js установлен в другом месте, укажите его полные пути. [Как открыть конфигурацию](https://modelcontextprotocol.io/docs/develop/connect-local-servers)

``` json
{
  "mcpServers": {
    "rdr2-files": {
      "command": "C:\\Program Files\\nodejs\\node.exe",
      "args": [
        "C:\\Program Files\\nodejs\\node_modules\\npm\\bin\\npx-cli.js",
        "--yes",
        "@modelcontextprotocol/server-filesystem@2.3.0",
        "--confine-roots",
        "D:\\Speles\\Red Dead Redemption 2",
        "D:\\REYRUN\\Lejupielade",
        "D:\\REYRUN\\Rezerve"
      ]
    }
  }
}
```

4.  Сохраните настройки, полностью закройте настольный ИИ-клиент и откройте его снова. При первом запуске npm скачает указанный общедоступный пакет. Параметр `--confine-roots` также не даст клиенту выйти за пределы заданных папок. Вызовите `list_allowed_directories`, чтобы увидеть разрешённые папки. Если папки игры нет, исправьте путь и выбор папок в клиенте, затем перезапустите подключение. Вызовите `get_file_info` для файла `RDR2.exe` в этой папке. Достаточно получить имя и размер.
5.  Файловый сервер работает локально. Скачайте файлы по ссылкам авторов ниже, распакуйте их в подготовленную папку и проверьте контрольные суммы. Игрок может запустить `Get-FileHash`, даже если у помощника нет терминала. Инструмент `copy_file` копирует файл без изменения байтов и требует свободное имя назначения. Если файл уже есть, проверьте его хеш и выполните шаги раздела 3 перед заменой. Если Windows отказывает в записи, попросите игрока подтвердить это копирование в Проводнике. Когда закончите, можно удалить только запись `rdr2-files` и снова открыть клиент. [Файловые операции и ограничения доступа к папкам](https://github.com/modelcontextprotocol/servers/blob/main/src/filesystem/README.md)

## 2. Скачайте перевод, плагин и загрузчик

1.  Скачайте архив **REYRUN-RDR2-LV.zip** по любой из двух ссылок. Кнопка «Code → Download ZIP» на GitHub скачивает снимок исходного кода. Ниже даны ссылки на готовый архив для игрока. [Скачать с сайта](https://reyrun-rdr2-latviski.runcisreinis.chatgpt.site/download/REYRUN-RDR2-LV.zip) · [Скачать тот же архив с GitHub](https://raw.githubusercontent.com/runcisreinis-glitch/REYRUN-RDR2-Latvian/main/REYRUN-RDR2-LV.zip)
2.  Откройте PowerShell в папке загрузки, выполните первую команду ниже и сверьте SHA-256 с таблицей. Распакуйте ZIP в новую пустую папку. Внутри находятся `Latvian Translation.xml`, `UZSTADISANA-LV.txt` и `INSTALL-EN.txt`. Выполните вторую команду в распакованной папке. Если хеш отличается, остановите установку и сверьте файл со списком контрольных сумм проекта. [Контрольные суммы проекта](https://github.com/runcisreinis-glitch/REYRUN-RDR2-Latvian/blob/main/SHA256SUMS.txt)
3.  Для игры нужен плагин **Universal RDR2 String Translator**. Если у игрока уже есть рабочая версия, оставьте её. В остальных случаях извлеките `UniversalRDR2StringTranslator.asi` из основного архива автора. Если Nexus попросит войти в аккаунт, игрок может сделать это в своём браузере. [Плагин RacerMouze](https://www.nexusmods.com/reddeadredemption2/mods/10214)
4.  Плагину нужен **загрузчик ASI**. Оставьте работающий `dinput8.dll` в папке игры. Если там другой загрузчик ASI, сохраните существующие настройки и уточните совместимость у авторов модов. Здесь проверяется вариант с dinput8.dll. Сначала выясните, как он вписывается в текущую установку. При чистой установке извлеките `dinput8.dll` из папки `bin` в архиве **Script Hook RDR2**. Для этого плагина перевода из архива понадобится только этот файл. [Скачать у Александра Блейда](https://www.dev-c.com/rdr2/scripthookrdr2/)

``` powershell

Get-FileHash -Algorithm SHA256 -LiteralPath '.\Latvian Translation.xml'
```

## 3. Сохраните старые файлы и установите новые

1.  Осмотрите папку с `RDR2.exe`. Запишите её полный путь. Включите показ расширений файлов в Проводнике. Найдите файлы, имена которых заканчиваются на `Translation.xml`, старый плагин `rdr2-translator.asi`, а также `UniversalRDR2StringTranslator.asi` или `dinput8.dll`, если они уже установлены. Запишите первоначальное имя и хеш каждого файла.
2.  Если единственный основной XML имеет правильное имя и опубликованный хеш, обе зависимости работают и старого плагина нет, переходите к проверке. В остальных случаях создайте новую резервную папку за пределами игры, запишите её путь и сделайте в ней две подпапки. В `before` поместите проверенные копии, а в `inactive` перенесите отключённые файлы из игры. Перед заменой скопируйте файл в `before` под прежним именем и сверьте хеш.
3.  Оставьте активным один основной файл `*Translation.xml`. После проверки копий перенесите конфликтующие XML и старый `rdr2-translator.asi` в `inactive`. При замене плагина также перенесите туда старый экземпляр, чтобы его имя освободилось в папке игры. Уже правильные файлы и другие моды оставьте на месте.
4.  Поместите недостающие зависимости и файл `Latvian Translation.xml` прямо рядом с `RDR2.exe`. Запишите каждый добавленный и заменённый файл. При обновлении пользуйтесь контрольными суммами нового выпуска и тем же порядком резервного копирования. Если копирование прервалось, сравните содержимое папки с записью, прежде чем продолжать или восстанавливать файлы.

## 4. Проверьте установленный перевод

Откройте PowerShell в папке игры и выполните команды ниже. Они только читают состояние файлов и выводят список активных основных переводов. Затем проверьте, загрузились ли плагин и загрузчик в самой игре.

``` powershell
'RDR2.exe','dinput8.dll','UniversalRDR2StringTranslator.asi','Latvian Translation.xml' |
    ForEach-Object { [pscustomobject]@{ File = $_; Present = Test-Path -LiteralPath $_ -PathType Leaf } }
Get-ChildItem -LiteralPath . -Force -File | Where-Object { $_.Name -like '*Translation.xml' }
Test-Path -LiteralPath '.\rdr2-translator.asi'
Get-FileHash -Algorithm SHA256 -LiteralPath '.\Latvian Translation.xml'
```

Для четырёх обязательных файлов результат должен быть `True`, в списке основных XML должен остаться один файл, а для старого плагина ожидается `False`. Сверьте хеш установленного XML с данным выпуском. Если нет папки игры или одной из зависимостей, укажите, чего именно не хватает.

1.  Выберите базовый язык игры **English**. В Steam откройте **«Свойства»** игры и выберите язык. Настройки языка в Rockstar Games Launcher находятся в разделе **«Настройки»**. В Epic откройте меню профиля, выберите **«Настройки»**, затем **English** и перезапустите программу, если она об этом попросит. [Настройки языка в Rockstar](https://support.rockstargames.com/articles/6ZSsAaVCIBrg5m6Ovc5EDe/how-to-change-the-language-in-red-dead-redemption-2)
2.  Запустите игру как обычно и откройте **сюжетный режим**. В меню паузы найдите **Iestatījumi** (настройки), затем **Vadība** (управление) и **Taustiņu piesaiste** (назначение клавиш). Включите субтитры и откройте сцену с диалогом. Субтитры должны появиться на латышском. Озвучка останется оригинальной.
3.  Если меню осталось английским, проверьте, какую копию игры открыла программа запуска, в той ли папке лежат файлы, каковы их настоящие расширения, установлены ли зависимости и нет ли других XML. Если меню на латышском, а диалоги идут без текста, проверьте настройки субтитров и выберите сцену с речью. Если ошибка появилась после обновления игры, уточните у авторов совместимость загрузчика и плагина.
4.  Сообщите игроку, где установлен перевод, где лежит резервная копия и какой текст появился на экране. Если игру видит только игрок, спросите, что отображается в разделе **Vadība**.

### Как проверить текст в запущенной игре

Для каждого пункта запишите «увидел», «отличается» или «не проверял». Подойдёт существующее сохранение сюжетного режима. Начинать историю заново не нужно.


| Где смотреть                      | Что проверить                                                                                                                                                                                                                                                                         |
|-----------------------------------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| Меню паузы и настройки            | Найдите «Karte» (карта) и «Iestatījumi» (настройки). В настройках поищите «Vadība» (управление), «Ekrāns» (экран) или «Skaņa» (звук).                                                                                                                                                 |
| Назначение клавиш                 | Откройте «Vadība» и **войдите** в «Taustiņu piesaiste». Запишите название одного действия на латышском и назначенную ему клавишу. Если игрок согласен проверить переназначение, запишите прежнюю клавишу, выберите свободную клавишу, проверьте действие и верните старое назначение. |
| Подсказка во время игры           | В обучении верховой езде показаны клавиша и латышский текст о том, как ехать быстрее. Убедитесь, что виден символ клавиши. Служебный код выглядит так: `~INPUT_…~`.                                                                                                                   |
| Цель задания                      | Во время сюжетной миссии дождитесь появления цели или откройте список её целей. Запишите название миссии и фактическую инструкцию игроку. Обучение верховой езде отмечайте отдельно, в предыдущей строке.                                                                             |
| Диалог, когда управление у игрока | Начните разговор с другим персонажем, когда сами управляете героем. Проверьте субтитры именно этого разговора.                                                                                                                                                                        |
| Субтитры в сюжетном ролике        | Отдельно проверьте реплику в ролике. В одной из вступительных сцен звучит фраза с субтитрами «Bet mēs zaudējām dažus cilvēkus.» Проверьте латышские буквы и убедитесь, что строка помещается на экране.                                                                               |

Семь опубликованных кадров показывают меню паузы, настройки, вход в назначение клавиш, подсказку для верховой езды, субтитры в ролике, должности в титрах и начало главы. Для проверки цели миссии, списка действий и клавиш, переназначения и диалога во время управления нужны отдельные наблюдения. Запишите версию игры и текст на экране.

## 5. Восстановите прежнюю установку

Закройте игру. По журналу установки перенесите добавленный XML из папки игры и восстановите прежний перевод под исходным именем.
