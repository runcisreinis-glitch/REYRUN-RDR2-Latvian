Ja spēlētājs vēlas pārbaudīt arī pārsaisti, fiksē veco vērtību, izvēlies brīvu taustiņu, izmēģini darbību un atjauno iepriekšējo vērtību. Bez piekrišanas vadības iestatījumus nemaini. |
| Norāde spēles laikā | Jāšanas pamācībā apskati frāzi par ātrāku jāšanu un taustiņa simbolu. Pārbaudi, ka simbola vietā nav palicis redzams tāds tehnisks kods kā `~INPUT_…~`. |
| Misijas mērķis | Aktīvas stāsta misijas laikā sagaidi mērķa tekstu vai atver konkrētās misijas uzdevumu sarakstu. Pieraksti misiju un tieši spēlētājam doto uzdevumu. Jāšanas pamācības tekstu reģistrē iepriekšējā rindā. |
| Dialogs spēlēšanas laikā | Kamēr spēlētājs kontrolē varoni, noklausies sarunu ar citu tēlu un pārbaudi tieši šā dialoga subtitrus. |
| Filmiņas subtitri | Atsevišķi pārbaudi runāto tekstu stāsta ainā. Ievada piemērā redzams „Bet mēs zaudējām dažus cilvēkus.” Pārbaudi arī garumzīmes un to, vai visa rinda ietilpst ekrānā. |
| Veidotāju titri un nodaļas nosaukums | Titros pārbaudi profesijas nosaukumu, piemēram, „Vides māksla”. Nodaļas sākumā latviskais „1. nodaļa: Kolters” redzams zem oriģinālā grafiskā uzraksta. |

Publicētajos septiņos ekrānattēlos redzama izvēlne, iestatījumi, taustiņu piesaistes sadaļas nosaukums, jāšanas norāde, filmiņu subtitri, veidotāju amati un nodaļas ievads. Pilns misijas mērķis, atvērts darbību un taustiņu pāru saraksts, taustiņa pārsaistes rezultāts un saruna, kamēr spēlētājs vada tēlu, jāapstiprina ar šiem atsevišķajiem testiem. Pārbaudes piezīmē norādi spēles versiju un ekrānā redzamo tekstu.

## 5. Atjauno iepriekšējo stāvokli

Aizver spēli. Pēc sava uzstādīšanas saraksta pārvieto jaunpievienoto XML ārpus spēles un atjauno iepriekšējo tulkojumu ar tieši tādu pašu nosaukumu. Ja tas izmantoja veco `rdr2-translator.asi`, vispirms pārvieto pašreizējo Universal spraudni ārpus spēles. Pēc tam atjauno vecos failus. Atjauno aizstāto palīgfailu iepriekšējās kopijas un salīdzini kontrolsummas. Iepriekš tīrā spēlē var izņemt arī pievienoto spraudni un ielādētāju. Ja citam modam vajag ielādētāju vai kopīgo spraudni, paturi to. Pirms spēlēšanas **Red Dead Online** izmanto šim režīmam tīru instalāciju. REYRUN pakotne paredzēta stāsta režīmam.
